# Core Conversion Flow — Feedme

## 사용자에게 보이는 결과

사용자는 웹 페이지 URL을 붙여넣기만 하면 본문이 정제된 Markdown으로 변환된 것을 확인하고, 그 내용을 그대로(또는 프롬프트를 앞에 붙여) 복사·다운로드·ChatGPT/Claude 새 대화로 바로 이어갈 수 있다.

## 승인된 범위

1. **입력**: URL 입력 필드, 지우기 버튼(입력값과 결과 화면을 모두 초기 상태로 리셋).
2. **변환**: 서버에서 URL의 페이지를 가져와 `defuddle`(npm 패키지, Node 환경에서는 `defuddle/node` + DOM 구현체 조합)로 본문을 Markdown으로 추출한다.
3. **결과 확인**: 페이지 제목·저자(확인 가능한 경우) 헤더와 렌더링된 Markdown을 함께 보여준다.
4. **내보내기**:
   - 복사하기: 제목/저자 헤더 + 원문 출처 + Markdown 본문을 클립보드에 복사.
   - `.md` 파일 다운로드: 동일한 내용을 `.md` 파일로 저장.
   - LLM으로 보내기: 대상(ChatGPT 또는 Claude)을 드롭다운으로 고르고 하나의 버튼("OOO로 보내기", 선택된 대상 이름이 즉시 반영됨)을 누르면, 선택된 프롬프트(있는 경우) + 제목/저자 헤더 + Markdown 본문이 클립보드에 자동 복사되고 해당 서비스의 새 대화 페이지가 새 탭으로 열린다. 사용자는 붙여넣기(Ctrl+V)만 하면 된다.
5. **프롬프트 선택**: 결과 화면에 프리셋 3종(요약해줘 / 한국어로 번역해줘 / 쉽게 설명해줘) + "직접 입력" 옵션을 제공한다. "직접 입력" 선택 시 텍스트 입력창이 나타나며, 이 입력값은 세션에 저장되지 않고 해당 1회 내보내기에만 적용된다. 프롬프트는 "LLM으로 보내기"에만 적용되며, 복사하기/`.md` 다운로드는 프롬프트 없이 헤더+본문만 내보낸다.
6. **다크모드 토글**: 라이트/다크 모드를 수동으로 전환할 수 있고, 선택값은 다음 방문에도 유지된다.

## 관찰 가능한 인수 기준

- URL을 붙여넣고 변환을 실행하면, 변환이 완료된 후 제목(있으면)·저자(있으면) 헤더와 Markdown 렌더링 결과가 화면에 나타난다.
- 변환이 진행되는 동안 사용자는 진행 중임을 알 수 있는 상태를 본다(로딩 표시).
- 지우기 버튼을 누르면 입력값과 결과 화면이 모두 초기 상태로 돌아간다.
- "복사하기"를 누르면 헤더+Markdown 본문이 클립보드에 복사되고 사용자는 성공 여부를 확인할 수 있는 피드백을 본다.
- ".md 다운로드"를 누르면 헤더+Markdown 본문이 담긴 `.md` 파일이 다운로드된다.
- 프리셋 프롬프트 중 하나를 선택하고, 드롭다운에서 대상(ChatGPT 또는 Claude)을 고른 뒤 "OOO로 보내기" 버튼을 누르면, 프롬프트+헤더+Markdown 본문이 클립보드에 복사되고 선택한 서비스의 새 대화 페이지가 새 탭에서 열린다. 드롭다운에서 대상을 바꾸면 버튼 문구도 즉시 바뀐다.
- "직접 입력"을 선택하면 텍스트 입력창이 나타나고, 다른 프롬프트로 바꾸거나 페이지를 새로고침하면 직접 입력한 텍스트는 남아있지 않다.
- 유효하지 않은 URL을 입력하거나 변환에 실패하면(사이트 접근 실패, 본문 추출 실패 등), 사용자는 실패했음을 알리는 메시지를 보고 재시도하거나 지우기로 초기화할 수 있다.
- 다크모드를 전환하면 즉시 화면 전체 테마가 바뀌고, 페이지를 새로고침해도 선택한 테마가 유지된다.

## 확정된 제약과 근거

- **변환 라이브러리는 `defuddle` 사용 확정.** 사용자 요구사항에 명시된 필수 조건이며, 실제 공식 문서(https://defuddle.md/docs)로 다음을 확인함: npm 패키지명 `defuddle`, 브라우저에서는 순수 DOM 기반, Node.js 서버 환경에서는 `defuddle/node` + `linkedom` 또는 `jsdom` 같은 DOM 구현체가 필요, HTML/Markdown/JSON 출력과 title·author 등 메타데이터 추출을 지원. 별도 재확인 필요 조건: 벤더가 API나 필수 DOM 구현체 조합을 바꾸는 breaking release를 내는 경우.
- **defuddle.md(호스팅 서비스)가 아니라 npm 라이브러리를 자체 서버에서 실행.** defuddle 저장소는 `defuddle.md` 호스팅 API도 제공하지만(URL 앞에 접두사로 붙이는 방식), 사용자가 임의로 붙여넣는 URL을 제3자 서비스로 그대로 전달하지 않기 위해, 그리고 요구사항이 "라이브러리 필수"로 명시했기 때문에 자체 서버(Node.js)에서 라이브러리를 직접 실행하는 방식으로 확정.
- **"ChatGPT·Claude로 열기"는 클립보드 자동 복사 + 새 탭 열기 방식으로 확정.** ChatGPT(chatgpt.com)와 Claude(claude.ai) 모두 URL 쿼리 파라미터(`?q=`)로 새 대화에 프롬프트를 프리필하는 기능을 공식 문서로 보장하지 않으며(ChatGPT는 브라우저 확장 없이는 비공식, Claude 웹은 공식 문서에 언급 없음), 설사 동작하더라도 URL 길이 제한 때문에 일반적인 웹 기사 분량의 Markdown 전체를 담을 수 없다. 이 조사 결과를 사용자에게 제시했고, 사용자가 자동 복사+새 탭 열기 방식을 확정함.
- **defuddle에 대한 벤더 공식 에이전트 컨텍스트(llms.txt 등 소비자용 문서)는 확인되지 않음.** GitHub 저장소(`kepano/defuddle`)의 `CLAUDE.md`는 defuddle 자체를 개발하는 기여자용 내부 문서(소스 구조, 빌드/테스트 절차)이며 이 프로젝트처럼 defuddle을 소비하는 애플리케이션에 설치할 대상이 아니어서 설치하지 않음.

## 가정(비용이 낮고 되돌리기 쉬움)

- 다크모드 토글은 라이트/다크 수동 전환이며 기본값은 시스템 설정을 따르고, 선택값은 로컬(브라우저)에 저장된다.
- 내보내는 콘텐츠(복사/다운로드/LLM 열기)는 제목·저자(확인 가능한 경우)와 원문 출처 URL을 짧은 헤더로 포함한 뒤 Markdown 본문이 이어지는 형태다.
- `.md` 다운로드 파일명은 페이지 제목 기반으로 만들고, 제목을 알 수 없으면 일반적인 기본 파일명을 사용한다.
- 계정/로그인 기능은 없으며, 변환 이력을 저장하거나 다시 불러오는 기능도 없다.

## 범위 밖 영역과 이유

- **자바스크립트 렌더링이 필요한 SPA 페이지의 완전한 본문 추출**은 범위 밖이다. `defuddle`은 서버에서 받은 정적 HTML의 DOM을 분석하는 방식이라 브라우저 JS 실행 없이는 클라이언트 렌더링 콘텐츠를 볼 수 없다. 헤드리스 브라우저 렌더링(Playwright 등)은 이번 작업 단위에 포함하지 않는다.
- **로그인이 필요한 페이지·페이월 콘텐츠의 우회 접근**은 범위 밖이다. 이 서비스는 공개적으로 접근 가능한 정적 HTML만 대상으로 한다.
- **변환 이력 저장/재열람**은 범위 밖이다. 요구사항에 명시되지 않았고, "직접 입력 프롬프트는 저장하지 않음"이라는 요구와도 방향이 맞다.

## 유예된 사항

- 없음 — 사용자가 제시한 요구사항 범위 안에서 구현에 필요한 결정은 모두 해결되었다.

## 남은 위험

- **동적 렌더링 페이지에서의 추출 품질 저하**: 사이트가 본문을 클라이언트 JS로 그리는 경우, 변환 결과가 비어 있거나 불완전할 수 있다. 사용자가 이런 사이트를 자주 다룬다면 헤드리스 렌더링 도입이 재고될 수 있다.
- **차단된 요청(anti-bot, rate limit, 지역 차단 등)**: 서버가 대상 사이트로부터 접근을 거부당하면 변환이 실패한다. 실패 메시지로 이 사실을 알리는 것 이상의 우회 대응은 이번 범위에 포함하지 않는다.
- **클립보드 접근 권한**: 브라우저가 클립보드 쓰기를 차단하거나 사용자가 권한을 거부하면 "자동 복사"가 조용히 실패할 수 있어, 복사 실패 시에도 사용자가 알아챌 수 있는 피드백이 필요하다.
